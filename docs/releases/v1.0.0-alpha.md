# EasyFi v1.0.0-alpha

- **Release date:** August 4, 2026
- **Platform:** Windows 10/11, 64-bit
- **Status:** Alpha preview

EasyFi v1.0.0-alpha is the first complete preview of the local-first financial
tracking workflow. It brings timesheets, wage estimates, employer payments,
outstanding balances, weekly reporting, and data-protection tools together in
one private Windows desktop application.

This release is intended for early use and feedback. Financial records stay on
your computer, with no account, subscription, cloud service, or network
connection required.

## Highlights

### Intuitive timesheets

- Record the date worked, clock-in time, clock-out time, and multiple unpaid
  breaks.
- Choose dates from an integrated calendar.
- Select times using a three-column hour, minute, and AM/PM picker.
- Calculate elapsed and paid time automatically, including overnight shifts.
- See regular pay, overtime pay, gross earnings, estimated tax, and estimated
  take-home pay before saving.
- Edit or delete existing shifts with automatic weekly overtime recalculation.
- Receive a warning before saving a possible duplicate shift.

### Flexible earnings rules

- Start the work week on any day—for example, Thursday through Wednesday.
- Create and manage multiple income sources or employers.
- Configure hourly rate, estimated tax percentage, overtime threshold, and
  overtime multiplier independently for each source.
- Preserve historical calculation snapshots when rates or rules change later.

### Employer payments and amount owed

- Record partial or multiple payments and assign them to the appropriate income
  source and work week.
- Assign each payment to a pay period covering 1–8 weeks, including biweekly
  payroll, without duplicating the payment across weekly totals.
- Track gross wages earned, employer payments received, the remaining balance,
  and any overpayment.
- Carry unpaid balances forward across work weeks and apply new payments against
  the full running employer balance.
- Edit, delete, and duplicate-check payment records.

EasyFi defines the outstanding employer balance as:

```text
amount owed = gross earned wages - employer payments received
```

Estimated tax and take-home pay are shown separately and never reduce the gross
amount an employer owes.

### Weekly overview

- Review paid time, regular hours, overtime, gross wages, payments, and balances
  for a selected work week.
- Filter the dashboard by income source.
- Compare paid time and gross wages with the previous week.
- View per-employer owed, paid-in-full, and overpaid status.

### Local data protection

- Store all application data in a local SQLite database.
- Create verified manual backups.
- Enable automatic daily backups with configurable retention.
- Validate restore files before use and create a pre-restore recovery copy.
- Run SQLite integrity checks from the Settings screen.
- Export settings, income sources, shifts, breaks, and payments to CSV.

### Native Windows experience

- Use the standalone `EasyFi.exe` without installing Python.
- Run without a console window or third-party runtime dependencies.
- Render text and controls with Windows Per-Monitor V2 DPI awareness.
- Use a polished dark-green interface across Overview, Timesheet, Payments, and
  Settings.

## Installation

1. Download or copy `EasyFi.exe` to a folder of your choice.
2. Double-click the executable.
3. Begin in **Settings** to confirm the work-week start, default shift times,
   backup preferences, and income-source rules.

EasyFi stores personal data separately from the executable:

```text
%LOCALAPPDATA%\EasyFi\easyfi.db
```

Automatic backups are stored in:

```text
%LOCALAPPDATA%\EasyFi\backups
```

You can move or replace the executable without moving or deleting your data.

> Windows may display an **Unknown publisher** notice because this alpha build
> is not digitally signed.

## Upgrading from an earlier development build

- Existing data in `%LOCALAPPDATA%\EasyFi` is reused automatically.
- Database migrations run during application initialization when required.
- Create a manual backup from **Settings → Data safety** before upgrading.
- Do not delete the EasyFi application-data folder when replacing the
  executable.

## Alpha limitations

- The packaged application currently targets 64-bit Windows.
- EasyFi is designed for one local user and does not provide cloud sync,
  multi-device synchronization, or shared accounts.
- CSV data can be exported, but there is no CSV import workflow yet.
- Tax values are user-configured planning estimates, not tax-filing or financial
  advice.
- The executable is not digitally signed and may trigger a Windows reputation
  prompt.
- As an alpha release, workflows and the database schema may continue to evolve.
  Keep automatic backups enabled and retain an independent backup of important
  records.
